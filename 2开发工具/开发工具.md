## gcc/g++

`gcc -E/-S/-c .c文件 -o .i/.s/.o目标文件`

1. 预处理`-E`->`.i`
2. 编译（生成汇编）`-S`->`.s`
3. 汇编（生成机器可识别代码）`-c`->`.o`
4. 连接（生成可执行文件或库文件）

`-DX=xxx`：定义宏X=xxx

**预处理的本质就是改编辑我们的文本代码。**

条件编译的用途：

1. 软件进行专业度、收费情况的区分（业务上），对代码进行动态裁剪。
2. 内核源代码采用条件编译进行代码裁剪
3. 开发工具、应用软件

## 库

1. 动态库：Linux(.so) windows(.dll)
2. 动态库：Linux(.a) windows(.lib)

**动态链接：自己实现的方法通过地址跳转到库里面找到相应地址的方法。**

**静态连接：库里的方法拷贝到自己的文件里，调用时直接在自己的文件里找。**

动静态库对比：

1. 动态库形成的可执行程序提及一定很小。
2. 可执行程序对静态库的依赖度小，动态库不能缺失。
3. 程序运行需要加载到内存，静态连接会形成大量重复代码。
4. 动态链接比较节省资源。

所谓库，就是.o文件的集合。

## make/makefile

make是一个命令，makefile是一个文件

基本概念：依赖关系，依赖方法

```makefile
依赖关系
[Tab]依赖方法
```

`.PHONY:[文件]`——>伪目标：表示文件总是被执行，对应的依赖关系与依赖方法。

1. 默认老代码不做重新编译，不用`.PHONY`修饰，节省编译时间。
2. make怎么知道bin与.c谁新谁旧？

- 根据文件ACM时间，文件=内容+属性。
- 看两者谁的M时间更新，如果.c更新，那么就会重新编译。

依赖方法也可以不止一行。

`%.c`把当前路径下所有`.c`文件全部展开。

`$^`：(`.o`->`BIN`)所有依赖文件	`$@`：当前目标文件。

`$<`：(`.c`->`.o`)第一个依赖文件。

`SRC=$(wildcard *.c)`：所有`.c`文件。	`OBJ=$(SRC:.c=.o)`：将`.c`替换为`.o`。

## 进度条程序

`.h`：

```c
#pragma once

#include <string.h>
#include <unistd.h>
#include <stdio.h>

void progress_v1();
void FlushProgress(double total,double current);
```

`progress.c`

```c
#include "progress.h"
#define NUM 101
#define STYLE '='

void progress_v1()
{
    char buffer[NUM];
    memset(buffer,0,sizeof(buffer));
    const char* label="|/-\\";
    int len=strlen(label);
    int cnt=0;
    while(cnt<=100)
    {
        buffer[cnt]=STYLE;
        printf("[%-100s][%d%%][%c]\r",buffer,cnt,label[cnt%len]);
        fflush(stdout);
        usleep(10000);
        cnt++;
    }
    printf("\n");
}
```

`main.c`

```c
#include "progress.h"

int main()
{
    progress_v1();
    return 0;
}
```

`Makefile`

```makefile
SRC=$(wildcard *.c)
OBJ=$(SRC:.c=.o)
BIN=progressbar

$(BIN):$(OBJ)
	gcc -o $@ $^
%.o:%.c
	gcc -c $<
.PHONY:
clean:
	rm -f $(OBJ) $(BIN)
```
